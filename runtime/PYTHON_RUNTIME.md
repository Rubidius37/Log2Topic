# Bundled Python runtime

Log2Topic distributions include the official 64-bit Windows embeddable package for CPython 3.13.15.

- Source: https://www.python.org/downloads/release/python-31315/
- Archive: `python-3.13.15-embed-amd64.zip`
- SHA-256: `D1F04D990AEE1253D8569E8E5104E30FA9F5FA830899F14843448872D936A2CF`

The archive is extracted locally on first launch. Its `LICENSE.txt` is included inside the official archive. The extracted `runtime/python/` directory is generated and is not tracked by Git.
