# Windows 자동 업데이트

Log2Topic은 트레이가 시작된 후 잠시 뒤 GitHub의 최신 릴리스를 확인하고, 이후 6시간마다 다시 확인합니다. 트레이 메뉴에서 수동으로 업데이트를 확인할 수도 있습니다. 트레이 메뉴 상단에는 현재 설치된 버전이 표시됩니다.

릴리스에는 버전이 포함된 `Log2Topic-windows-v1.0.2.zip`과 같은 파일이 포함되어 있어야 합니다. GitHub에서 SHA-256 다이제스트를 제공하면 업데이트 프로그램이 이를 검증합니다. 업데이트가 시작되면 설치할 버전이 알림에 표시되고, 애플리케이션 파일을 교체한 뒤 설치 완료 대화상자가 표시됩니다. 대화상자에서 다시 시작을 선택하면 새 버전의 트레이가 실행되며, 나중에 다시 시작하려면 설치 폴더의 `Log2Topic.exe`를 실행하면 됩니다. `Workspace`, `runtime`, `scripts/.runtime` 폴더는 유지됩니다.

릴리스를 배포하려면:

1. 소스 코드를 수정하고 변경 사항을 커밋합니다.
2. 기존 릴리스보다 높은 `v1.0.1`과 같은 시맨틱 버전 태그를 만들고 푸시합니다. 같은 태그의 ZIP만 교체하면 이미 설치된 버전보다 새 버전으로 인식되지 않습니다.
3. GitHub Actions가 Windows 실행 파일을 빌드하고 `Log2Topic-windows-v버전.zip` 형식의 파일을 게시합니다.

설치 완료 대화상자에서 다시 시작하지 않은 경우에도 업데이트 파일은 이미 설치된 상태입니다. 트레이 메뉴를 다시 표시하려면 설치 폴더의 `Log2Topic.exe`를 직접 실행하세요.

업데이트 프로그램이 처음 포함된 릴리스는 수동으로 설치해야 합니다. 이후 릴리스부터는 기존 설치본을 자동으로 업데이트할 수 있습니다. 업데이트 로그는 `scripts/.runtime/update.log`에 기록됩니다.
